# Stepik Java Calculator (Task 1)

Учебный проект, выполненный в рамках курса на Stepik: [Java для начинающих](https://stepik.org/course/283034/info).

Это консольный калькулятор на Java, реализующий базовые арифметические операции в бесконечном цикле. Проект демонстрирует навыки работы с вводом данных (`Scanner`), условными операторами и обработкой исключений.

## Функционал

- Сложение, вычитание, умножение и деление.
- Бесконечный цикл `while(true)` для выполнения нескольких операций подряд.
- Запрос на продолжение работы после каждого вычисления.
